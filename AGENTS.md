Agentic Development Skills
==========================

Required Skills
---------------

Before responding or starting work, read every linked `SKILL.md` in full. Descriptions alone are insufficient. Apply each skill where relevant, including progress updates, final replies, generated documents, and instructions to other agents. Do not wait for automatic loading or explicit invocation.

- Before delegating, give each agent the applicable skill paths and require it to read and follow them
- Check output against all applicable skills before sending it
- If a required skill cannot be read, report the missing path rather than silently skipping it
- If the task changes, read any newly applicable skills in full, including their required references, before continuing

| Skill | When To Load And Apply |
| --- | --- |
| [ddnomad-coding-style](.agents/skills/ddnomad-coding-style/SKILL.md) | When writing, editing, or formatting source code, comments, docstrings, or substantive code examples in documentation. |
| [ddnomad-docs-style](.agents/skills/ddnomad-docs-style/SKILL.md) | When writing, editing, or formatting project documentation prose and Markdown structure, not source comments or docstrings. |
